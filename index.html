GUIA DO MODELO

Uma condição por linha

Use as colunas abaixo. Também é possível substituir campo, operador e valor por uma coluna regra_sql. A célula pode usar AND, e ou apenas espaço/quebra de linha entre condições completas. Aceita IN, NOT IN, >, >=, <, <=, = e <>. Informe listas separadas por vírgulas, sem parênteses. Os parênteses são adicionados na montagem do SQL. Expressões com OR, funções ou agrupamentos lógicos são sinalizadas para revisão.

O portal gera uma prévia SQL a partir de campo, operador e valor. As condições de um transtype são combinadas com AND. Os demais atributos devem ser iguais em todas as linhas desse transtype. Formate códigos e contas como Texto no Excel para preservar os zeros à esquerda.

LAYOUT DE ENTRADA

Cadastrar ou editar layout

Importe Excel ou CSV com campo_produto;campo_dataprep;tipo. campo_produto é opcional; campo_dataprep e tipo são obrigatórios. A prévia SQL escreve o campo DataPrep.

Arquivos de layout do projeto

Cada layout é armazenado em um JSON na pasta layouts/, com datas de cadastro e alteração.
